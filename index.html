📘 Mengenal Kelas-Kelas Alamat IPv4

Dalam arsitektur jaringan komputer, alamat IPv4 dibagi menjadi beberapa kelompok kelas untuk mempermudah manajemen alokasi perangkat berdasarkan skala jaringan:

Kelas Oktet Pertama Default Netmask Kegunaan Utama
Kelas A 1 - 126 /8 (255.0.0.0) Jaringan Skala Raksasa (Jutaan Host)
Kelas B 128 - 191 /16 (255.255.0.0) Perusahaan Menengah - Besar
Kelas C 192 - 223 /24 (255.255.255.0) Jaringan Lokal, Rumah, & UMKM
Kelas D 224 - 239 Tidak ada Komunikasi Multicast (Data Kelompok)

Penjelasan Singkat:

  • Kelas A: Menyediakan sedikit ID jaringan, namun setiap jaringan mampu menampung hingga 16,7 juta perangkat.
  • Kelas B: Membagi porsi seimbang antara identitas jaringan dan jumlah perangkat (maksimal 65.534 host per jaringan).
  • Kelas C: Kelas yang paling sering ditemui sehari-hari. Sangat efisien untuk jaringan lokal berskala kecil (maksimal 254 host).
  • Kelas D: Tidak memiliki segmen host dan tidak digunakan untuk komputer biasa. Kelas ini dirancang khusus untuk transmisi data multicast (seperti video konferensi atau protokol routing).
