📘 Mengenal Kelas-Kelas Alamat IPv4

Dalam arsitektur jaringan komputer, alamat IPv4 dibagi menjadi beberapa kelompok kelas untuk mempermudah manajemen alokasi perangkat berdasarkan skala jaringan:

Kelas Oktet Pertama Default Netmask Kegunaan Utama
Kelas A1 - 126/8 (255.0.0.0)Jaringan Skala Raksasa (Jutaan Host)
Kelas B128 - 191/16 (255.255.0.0)Perusahaan Menengah - Besar
Kelas C192 - 223/24 (255.255.255.0)Jaringan Lokal, Rumah, & UMKM
Kelas D224 - 239Tidak adaKomunikasi Multicast (Data Kelompok)

Penjelasan Singkat:

  • Kelas A: Menyediakan sedikit ID jaringan, namun setiap jaringan mampu menampung hingga 16,7 juta perangkat.
  • Kelas B: Membagi porsi seimbang antara identitas jaringan dan jumlah perangkat (maksimal 65.534 host per jaringan).
  • Kelas C: Kelas yang paling sering ditemui sehari-hari. Sangat efisien untuk jaringan lokal berskala kecil (maksimal 254 host).
  • Kelas D: Tidak memiliki segmen host, dirancang khusus untuk transmisi data multicast (seperti video konferensi).

📝 Panduan Cara Menghitung Subnetting Secara Manual

Bagaimana mesin kalkulator di atas bekerja? Mari kita bedah contoh studi kasus pencarian parameter jaringan menggunakan metode matematika manual.

Studi Kasus: Menghitung IP 192.168.1.10 dengan Prefiks /26

Prefiks /26 berarti ada 26 angka biner satu (1) berurutan, dan sisanya nol (0) hingga total memenuhi batas susunan 32 bit. Jika dituliskan dalam bentuk biner lengkap menjadi:

11111111.11111111.11111111.11000000

Dari mana datangnya angka desimal 255.255.255.192?
Setiap kelompok 8 bit (oktet) dihitung menggunakan konversi biner-ke-desimal berdasarkan posisi bobot bitnya (128, 64, 32, 16, 8, 4, 2, 1) dari kiri ke kanan:

Oktet Bentuk Biner Proses Hitung Desimal Hasil Desimal
Oktet 111111111128 + 64 + 32 + 16 + 8 + 4 + 2 + 1255
Oktet 211111111128 + 64 + 32 + 16 + 8 + 4 + 2 + 1255
Oktet 311111111128 + 64 + 32 + 16 + 8 + 4 + 2 + 1255
Oktet 411000000128 + 64 + 0 + 0 + 0 + 0 + 0 + 0192

1. Mencari Jumlah Subnet:
Rumus: 2x (di mana x adalah banyaknya angka biner 1 pada oktet terakhir).
Pada oktet ke-4 prefiks /26, terdapat 2 angka satu (11000000). Maka Jumlah Subnet = 22 = 4 Subnet (Artinya satu segmen jaringan besar dipecah menjadi 4 blok subnet mandiri).

2. Mencari Jumlah Host per Subnet:
Rumus: 2y - 2 (di mana y adalah banyaknya angka biner 0 pada oktet terakhir).
Sisa biner kosong pada oktet terakhir adalah 6 angka nol (11000000). Maka Jumlah Host = 26 - 2 = 64 - 2 = 62 Host Valid yang siap dialokasikan ke perangkat.

3. Mencari Blok Subnet & Rentang Alamat:
Blok didapat dari mengurangi angka maksimal desimal per oktet (256) dengan nilai oktet terakhir netmask: 256 - 192 = 64.
Maka kelipatan blok subnetnya adalah: 0, 64, 128, 192. Karena IP kita 192.168.1.10 berada di blok pertama (antara rentang 0 sampai 63), didapatkan hasil parameter jaringan:

Network ID : 192.168.1.0 (Alamat identitas subnet)
Host Pertama : 192.168.1.1 (IP pertama yang bisa dipakai perangkat)
Host Terakhir: 192.168.1.62 (IP terakhir yang bisa dipakai perangkat)
Broadcast ID : 192.168.1.63 (Alamat pengiriman data massal)

📘 Mengenal Alokasi & Struktur Alamat IPv6

Alamat IPv6 berukuran 128-bit (4 kali lipat dari IPv4) dan ditulis menggunakan format heksadesimal yang dibagi menjadi 8 kelompok blok (disebut *hextet*) dipisahkan dengan tanda titik dua (:).

Jenis Alamat IPv6 Populer:

  • Global Unicast Address (2000::/3): Alamat IP publik yang dapat dirouting secara global di jaringan internet publik global.
  • Link-Local Address (fe80::/10): Alamat otomatis yang digunakan untuk komunikasi antar perangkat dalam satu segmen lokal tanpa router.
  • Unique Local Address (fc00::/7): Alamat privat dalam versi IPv6, ekuivalen dengan segmen IP privat di IPv4.
